# AI Justice Department Assistant

A retrieval-augmented generation (RAG) tool that answers questions about Indian law using only the documents you provide. Answers include citations to the relevant act and section.

---

## Setup

**1. Install dependencies**

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

pip install -r requirements.txt
```

**2. Configure the LLM**

```bash
cp .env.example .env
```

Open `.env` and set `LLM_PROVIDER` to `openai`, `gemini`, or `ollama`, then fill in the matching API key and model name.

---

## Add documents

Place PDF or TXT files of Indian statutes and regulations in `data/docs/`. Subdirectories are supported.

```
data/docs/
    rti_act_2005.pdf
    ipc_1860.txt
    consumer_protection_act_2019.pdf
```

---

## Ingest documents

Run once after adding or changing files in `data/docs/`:

```bash
python ingest.py
```

This embeds the documents and saves a local FAISS index to `data/index/`.

---

## Start the server

```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

Open `http://localhost:8000` in a browser.

---

## Run evaluation

Place a CSV or JSON file in `data/eval/` with columns `question`, `reference_answer`, and optionally `source_section`.

**CSV example:**
```
question,reference_answer,source_section
What is the time limit to respond to an RTI request?,Public authorities must reply within 30 days.,Section 7
```

**JSON example:**
```json
[
  {
    "question": "What is the time limit to respond to an RTI request?",
    "reference_answer": "Public authorities must reply within 30 days.",
    "source_section": "Section 7"
  }
]
```

Then run:

```bash
python evaluate.py
```

Results are saved to `data/eval/results.csv` and a summary table is printed.

---

## Project structure

```
data/docs/          Legal documents (PDF, TXT)
data/eval/          Evaluation QA file and results
data/index/         FAISS vector index (generated by ingest.py)
static/             index.html, style.css, app.js
ingest.py           Document loading, chunking, and embedding
rag.py              Retrieval and LLM answer generation
app.py              FastAPI server
evaluate.py         Evaluation script
requirements.txt
.env.example
```

---

## Notes

- Re-run `ingest.py` whenever you add or update documents.
- The assistant only uses the provided documents. It will not speculate beyond them.
- For Ollama, make sure the Ollama server is running before starting the app.
